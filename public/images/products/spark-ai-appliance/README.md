# Spark AI Appliance Product Asset Library

This directory is the canonical product image library for Spark AI Appliance across the website, investor materials, brochures, and ODM communication.

## Naming Rules

- Use stable versioned filenames only.
- Do not use temporary names such as `final-final`, `new2`, `latest`, or `copy`.
- Replace TODO assets in place using the same filename after an approved render is available.
