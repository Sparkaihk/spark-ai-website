# Brand Review Checklist

Use this checklist before publishing any website page, product brief, diagram, download, investor material or partner asset.

## Identity

- [ ] Company name is `Spark AI Technology Limited` where a legal name is required.
- [ ] Brand name is `Spark AI™` on the first prominent reference.
- [ ] Platform name is `Spark AI Knowledge Infrastructure`.
- [ ] Flagship product name is `Spark Appliance™`.
- [ ] Product category is `Enterprise AI Cold Data Appliance` where category context is useful.

## Product naming

- [ ] No visible `RTX Spark Appliance`, `RTX Spark` or supplier-led product name remains.
- [ ] Navigation, Hero, CTA, Footer and cards use `Spark Appliance™`.
- [ ] Metadata, Open Graph, structured data and social images use the approved product name.
- [ ] Image alt text, captions and architecture labels use the approved product name.
- [ ] Internal legacy routes are not accidentally exposed as visible labels.

## NVIDIA boundary

- [ ] NVIDIA appears only in a technical context.
- [ ] `Powered by NVIDIA GPU` is used when appropriate.
- [ ] NVIDIA does not appear as product ownership or primary identity.
- [ ] Supplier claims and trademarks have been reviewed.

## Product accuracy

- [ ] Every capability is current, configuration-specific or clearly identified as roadmap.
- [ ] Quantitative claims have evidence, owner and scope.
- [ ] Architecture diagrams match the product boundary.
- [ ] Compliance, security and sovereignty language is qualified and reviewable.
- [ ] Downloadable documents match current website claims.

## Voice and conversion

- [ ] Headline communicates business value.
- [ ] Supporting copy explains how the product creates that value.
- [ ] The primary CTA matches the visitor’s likely next decision.
- [ ] Technical detail supports rather than replaces the product narrative.
- [ ] Chinese and English versions communicate the same meaning.

## Release evidence

- [ ] Source search completed for forbidden terms.
- [ ] Rendered-page search completed.
- [ ] Desktop and mobile layouts reviewed.
- [ ] Links and downloads verified.
- [ ] Metadata and indexability reviewed.
- [ ] Remaining exceptions include file, line, owner and reason.
