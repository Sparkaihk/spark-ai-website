# SPR-002 — Hardware Specification

**Status:** Draft  
**Owner:** Product Hardware and Engineering

## Purpose

Define the approved hardware configurations and evidence-backed limits of Spark Appliance™.

## Specification domains

- GPU configuration
- CPU and system memory
- Performance storage
- Capacity storage
- Blu-ray archival module
- Network interfaces
- Management interfaces
- Power, thermals and acoustics
- Physical dimensions and weight
- Serviceability and replacement units
- Environmental and deployment requirements
- Certifications and regional constraints

## Claims controls

Capacity, archival lifespan, performance and power claims must include configuration, test method and environmental assumptions.

NVIDIA terminology appears only as an accurate technology specification and never replaces the Spark Appliance™ product name.
