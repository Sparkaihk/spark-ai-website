# SES-002 — Website Architecture

**Status:** Draft  
**Owner:** Web Engineering

## Purpose

Define the maintainable application architecture for the Spark AI official website.

## Architecture principles

- Next.js App Router
- Server Components by default
- Client Components only for interaction and animation
- Shared content and navigation models
- Type-safe reusable component contracts
- Route-level metadata and structured data
- Explicit image dimensions and optimized delivery
- Bilingual content parity
- Accessible progressive enhancement

## Layer model

1. Routes and metadata
2. Page compositions
3. Product and narrative components
4. Design-system components
5. Content and localization
6. Assets and downloads
7. Analytics, SEO and verification

## Required outputs

- Route map
- Component ownership map
- Content source map
- Asset dependency map
- Redirect and compatibility policy
- Build and release verification process
