# SES-001 — Website Brand Migration

**Status:** Active  
**Owner:** Web Engineering

## Objective

Migrate all user-facing website surfaces to the approved Spark AI brand architecture without breaking compatibility routes, assets or SEO continuity.

## Required migration

- `RTX Spark Appliance™` → `Spark Appliance™`
- Supplier-led product names → `Spark Appliance™`
- Platform references → `Spark AI Knowledge Infrastructure`
- Technical supplier references retained only where accurate and clearly subordinate

## Scope

- Hero
- Product pages
- CTA
- Navigation and Footer
- Architecture diagrams
- Metadata and SEO
- Image alt text and captions
- Downloads and documentation

## Verification evidence

Every remaining legacy reference must include file path, line number and reason. Compatibility URLs and internal asset identifiers may remain until a deliberate route migration is approved.

## Dependencies

- SB-001 Brand OS
- SB-002 Brand Guidelines
- SPR-001 Spark Appliance™ PRD
