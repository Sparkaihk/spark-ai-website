# SES-004 — Design System

**Status:** Active  
**Owner:** Frontend Engineering

## Purpose

Translate SB-003 Visual Design System into reusable, accessible and performant implementation primitives.

## Engineering requirements

- TypeScript component APIs
- CSS variables as shared tokens
- CSS Modules or approved scoped styling
- Next/Image for production imagery
- Semantic HTML and keyboard access
- `prefers-reduced-motion` support
- Responsive behavior from 375px upward
- No hydration errors or avoidable layout shift
- Motion primarily through transform, opacity and SVG progress

## Component governance

Create a shared component only when the pattern is reusable across active product surfaces. Page-specific storytelling remains composable and must not be forced into generic cards.

## Release requirements

- Type check
- Lint
- Production build
- Desktop and mobile rendering review
- Accessibility review
- Broken-link and metadata review
